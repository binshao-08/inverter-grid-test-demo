# 逆变器并网测试数据整理工具

*Inverter Grid-Connection Test Data Processing*

把逆变器并网测试仪器导出的连续录波，整理成**按工况汇总、能回到曲线复核的结果**。测试人员可以从一行偏差或判定回看对应的测试条件和取样区间，再将汇总表与图表用于报告整理。

## 从仪器记录到逐工况结果

例如，做一组有功功率响应测试时，逆变器依次收到不同的功率设定值。仪器记录的是一条连续曲线，而报告需要逐步回答：**这一段对应哪个设定值？取了哪些点？平均功率偏了多少？**

| 原来的人工步骤 | 工具怎样处理 | 对复核的帮助 |
| --- | --- | --- |
| 在曲线上找工况边界，再逐段对照条件表 | 自动分段并匹配测试步；无法可靠匹配时提示缺步或待核对的段 | 让复核人员发现哪些测量结果可能配错了工况 |
| 手工挑选稳定区间、求均值、对照限值 | 选取取样窗口，计算代表值和偏差，并按给定限值标记结果 | 同时看到测量值、设定值和取样依据，便于判断异常来自哪里 |
| 在表格和图表之间反复复制、重画 | 导出 Excel 汇总表和可编辑图表 | 将数据、曲线和逐工况结果一起交给复核人员 |

工作版也覆盖谐波统计、直流分量和一阶响应分析。它处理测量和结果整理环节，正式判定仍需由测试人员依据适用标准和试验条件复核。

## 我的贡献与验证

我梳理测试人员的操作步骤，把工况匹配、取样窗口、偏差判定和异常提示整理成可核对的业务规则；用 AI 编程工具辅助实现，并核查汇总与导出结果是否符合预期。这个项目的关键取舍是：工况没对齐时要指出哪一步需要复核，不能只追求生成一张完整的表。

工作版通过了 71 项基础回归检查，覆盖分段、对齐和取样窗口等行为。下面的公开演示用另一套简化规则和虚构数据，可以直接手算核对；它不代表真实测试或合规结果。

## 用一个虚构工况验证结果

下载并在浏览器打开 [`index.html`](index.html)。示例有 12 个虚构的有功功率测点和 3 个设定值。第三段的目标是 **120 W**，绿色窗口内最后两点都是 **126 W**，所以均值是 **126 W**，偏差为 **+6 W**。把允许偏差从 **±5 W** 调到 **±6 W**，这一段会从「超出」变为「通过」，下载的 CSV 也会记录所选限值和判定。

| 工况 | 目标（W） | 取样均值（W） | 偏差（W） | 允许偏差为 ±3 W 时 |
| --- | ---: | ---: | ---: | --- |
| 1 | 60 | 60.5 | +0.5 | 通过 |
| 2 | 90 | 90.5 | +0.5 | 通过 |
| 3 | 120 | 126.0 | +6.0 | 超出 |

演示使用独立编写的简化逻辑，仅运行内置虚构数据，不接收文件。
