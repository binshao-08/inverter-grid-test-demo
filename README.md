# 逆变器并网测试数据整理工具

[在线体验演示](https://binshao-08.github.io/inverter-grid-test-demo/)

把有功功率录波整理成逐工况结果：在曲线上标出分段和取样范围，计算均值、偏差与判定，再导出 CSV 供复核。这个作品集项目展示了我如何把人工找段、取样、核对设定值的步骤整理成一个可重复的流程，并在工况数量不一致时停下来提示复核。

## 开始使用

下载后用浏览器打开 [`index.html`](index.html)。无需安装软件或联网，文件在当前页面内处理，不会上传或保存到浏览器存储。页面内置可下载的正常样例和缺工况样例，均为虚构数据。也可以导入符合以下格式的 CSV：

```csv
time_s,power_w
0,59
1,60
2,61
```

表头必须是 `time_s,power_w`，单位为秒和瓦。用 UTF-8 编码（可带 BOM）和点号小数，时间须非负且严格递增。文件最多 512 KB、5,000 个测点。修改参数后，点「计算工况汇总」更新图表和导出结果。

## 分段、取样和判定

1. **分段。** 相邻功率值之差的绝对值严格大于跳变阈值时开始新一段；默认阈值为 15 W。
2. **取样。** 每段用最后 N 个点求均值，默认 N 为 2。点数不足的段标为待复核。
3. **判定。** 输入按测试顺序排列的目标值，默认是 60、90、120 W。只有检测出的段数与目标数相同时，才按顺序配对；请结合曲线确认顺序。偏差为「取样均值 − 目标值」，其绝对值不超过容差时判为通过，默认容差为 ±3 W。
4. **导出。** CSV 保留分段和取样的时间范围、均值、目标值、偏差、容差与状态。段数与目标数不一致时，所有段标为待复核，仍可导出范围和均值；工具不会猜测缺的是哪一步，也不会继续给出通过或超出结论。

## 如何复核

- 正常样例在默认设置下应识别出三段，取样均值依次为 **60.5、90.5、126.0 W**。第三段目标为 120 W、偏差为 +6 W；容差为 ±3 W 时显示超出，改到 ±6 W 时应显示通过。
- 加载缺工况样例并保留三个目标值，页面应显示「识别出 2 段，有 3 个目标值」。导出的两行仍保留各自的测量结果，目标值和偏差留空，判定为「待复核」。

这是用通用方法独立实现的作品集演示，仅覆盖单指标录波的分段、取样、判定和导出。示例阈值并非并网测试标准；本工具的输出不用于实际检测或合规判定。
